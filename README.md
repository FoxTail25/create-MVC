# Custom PHP MVC Framework with Light ORM

Легковесный, расширяемый MVC-фреймворк, написанный на чистом PHP (без использования сторонних зависимостей) с целью глубокого изучения внутренней архитектуры современных веб-движков (Laravel, Symfony).

Проект полностью автономен и настроен на работу с базой данных **SQLite** «из коробки» — запуск и тестирование происходят мгновенно после клонирования репозитория.

## 🚀 Архитектурные особенности и ключевой функционал

* **Front Controller & Routing:** Единая точка входа (`index.php`). Маршрутизация на основе регулярных выражений с поддержкой динамических параметров (например, `/product/:id`) и автоматической нормализацией слэшей (trailing slash).
* **Контроллер инъекций (Reflection API):** Реализован продвинутый механизм диспетчеризации (`Dispatcher`). С помощью рефлексии фреймворк автоматически сопоставляет именованные параметры из URL-адреса с аргументами методов (экшенов) контроллера, избавляя от ручного разбора массивов.
* **Собственная Light ORM:** Разработан абстрактный слой моделей (`Core\Model`), автоматически генерирующий базовые SQL-запросы (`INSERT`, `SELECT`, `UPDATE`, `DELETE`) на основе ассоциативных массивов. Поддерживает быстрое переключение между MySQL и SQLite.
* **Безопасность данных (PDO Prepared Statements):** Полная защита от SQL-инъекций. Реализована автоматическая строгая типизация и привязка параметров (`bindValue`) для типов `int`, `bool`, `null` и `string`.
* **Централизованная обработка ошибок:** Сквозной перехват исключений через единый блок `try...catch` верхнего уровня. Система автоматически распределяет HTTP-статусы ответов (404 Not Found / 500 Internal Server Error) и делегирует отрисовку ошибок специализированному `ErrorController`, предотвращая падение сервера в «белый экран».
* **Инструменты отображения (View Engine):** Компонент рендеринга с использованием буферизации вывода (`ob_start`/`ob_get_clean`) и изоляцией контекста данных через `extract()`, обеспечивающий безопасное разделение логики и шаблонов (Layouts/Views).

## 🛠️ Архитектура папок (PSR-4)

* `Core/` — Объектно-ориентированное ядро фреймворка (Роутер, Диспетчер, Модель, Представление).
* `Project/` — Прикладная логика приложения.
  * `Config/` — Конфигурационные файлы и маршруты.
  * `Controllers/` — Контроллеры бизнес-логики.
  * `Models/` — Конкретные сущности базы данных.
  * `Views/` & `Layouts/` — HTML-шаблоны страниц.
  * `Database/` — Файл встроенной БД `database.sqlite`.

## 💻 Инструкция по локальному запуску

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/FoxTail25/create-MVC/
   ```
2. Настройте локальный сервер (например, Open Server, Apache или встроенный сервер PHP) так, чтобы корневой директорией была папка проекта.
3. Откройте сайт в браузере. База данных SQLite с демонстрационными товарами уже подключена и готова к работе!
